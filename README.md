# La Cámara

Directorio de los 53 representantes de la Cámara de Puerto Rico en el cuatrienio 2025–2028.

SPA Vite + React (sin router). Vistas: Caras, Hemiciclo, Ranking, Ficha y Conexiones. Fuente del roster: [camara.pr.gov/representante](https://www.camara.pr.gov/representante/). El distrito 31 figura con Roberto López Román. La Ficha publica solo hechos citados (vacío si no hay fuente). Conexiones marca HECHO vs INFERENCIA; el solape de pueblos es inferencia.

```bash
npm install
npm test
npm run dev
```
